# Практическое портфолио по информационной безопасности

## О себе

Студент 4 курса направления «Информационная безопасность телекоммуникационных систем» (КФУ). На практике развернул виртуальную инфраструктуру из машин Windows и Linux: настроил пользователей, групповые и парольные политики, права доступа через FreeIPA, межсетевое экранирование (iptables), проектировал локальные сети в Cisco Packet Tracer. Внедрил Wazuh для централизованного сбора и анализа журналов безопасности с базовыми правилами корреляции для выявления подозрительной активности. Работал с сертифицированным СЗИ НСД Dallas Lock 8.0: политика защиты, резервное копирование и восстановление данных, межсетевое экранирование, защита съёмных накопителей. Проводил сканирование и анализ уязвимостей (Nmap), тестирование веб-приложений (Burp Suite) на учебном стенде. Разрабатывал программы-шифраторы на Python и C# для понимания криптографических примитивов и векторов атак на обработку данных. Знаю и понимаю основы сетевых технологий, актуальные угрозы информационной безопасности по матрице, жизненный цикл злоумышленника, Active Directory и основы системного администрирования — это помогает оценивать не только технические уязвимости, но и векторы эскалации привилегий. Ищу позицию стажёра или младшего специалиста в сфере информационной безопасности, чтобы применять практические навыки в реальных задачах, развиваться в защите и расследовании инцидентов и расти вместе с командой.

## Навыки и инструменты
### Системное администрирование:
* Администрирование Windows и Linux
* FreeIPA, Active Directory: пользователи, группы, права доступа, парольные политики
* Резервное копирование и восстановление данных
* Виртуализация (VirtualBox и VMWare)
### Средства защиты информации и мониторинга событий:
* Wazuh SIEM: сбор и анализ журналов безопасности (Windows Event Log, Linux syslog)
* Настройка правил корреляции событий
* Dallas Lock 8.0: политика защиты, управление доступом, защита съёмных носителей, IDS/IPS, гарантированное удаление данных
### Сетевая безопасность:
* Межсетевое экранирование (iptables)
* Проектирование локальных сетей (Cisco Packet Tracer): IP-адресация, VLAN, DHCP, маршрутизация
* Модель OSI, TCP/IP, DNS, HTTP/HTTPS
### Тестирование безопасности:
* Nmap (сканирование и анализ сети)
* Burp Suite (анализ веб-приложений)
* OWASP Top 10, MITRE ATT&CK, Cyber Kill Chain
* Wireshark (анализ сетевого трафика)
### Разработка:
* Python (утилиты-шифраторы, автоматизация)
* C# (утилиты-шифраторы)
### Языки:
* Русский — родной
* Английский — B1 (чтение технической документации)
