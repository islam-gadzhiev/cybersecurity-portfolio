## Selected Projects

### Wazuh SIEM Lab

Развёртывание тестовой инфраструктуры Windows/Linux, подключение журналов к Wazuh SIEM и анализ событий безопасности.

**Topics:** SIEM, log analysis, Windows, Linux, SOC

### Linux & Windows Security Lab

Настройка пользователей, групп, прав доступа, парольных политик, sudo и других механизмов управления доступом.

**Topics:** IAM, Linux, Windows, access control

### Network Security Lab

Проектирование локальной сети в Cisco Packet Tracer с использованием IP-адресации, VLAN, DHCP и маршрутизации.

**Topics:** networking, VLAN, routing, TCP/IP

### Firewall & IDS/IPS

Практика настройки межсетевого экрана и правил фильтрации сетевого трафика с использованием iptables/nftables.

**Topics:** firewall, network security, IDS/IPS

### Cryptography with Python

Реализация учебных алгоритмов шифрования и анализа шифротекстов на Python.

**Topics:** Python, cryptography, Caesar cipher, Vigenère cipher, XOR, frequency analysis
